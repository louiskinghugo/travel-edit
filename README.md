# 旅行 專輯剪輯風格 Skill

以四份旅行參考素材整理的繁體中文 Codex Skill，包含逐作分析、版式與剪輯規則，以及本機素材清點、抽幀和預覽腳本。

## 開始使用

將本專案資料夾複製到你使用的 Codex skills 目錄，資料夾名稱維持 `zine-travel-edit`；也可以直接指定 [SKILL.md](SKILL.md) 請 Codex 讀取。範例：使用 `$zine-travel-edit` 分析我的旅行素材，提出分鏡與預覽方案。

- [逐作分析](references/作品分析.md)：三組 28 張圖片與一部 8 分 34 秒影片。
- [風格規則](references/風格規則.md)：留白、拼貼、年度系列與可跟做教學。
- [自動化使用方式](references/自動化.md)：Python、Pillow 與 FFmpeg。
- [驗證紀錄](references/驗證紀錄.md)：實際執行結果及限制。
- [無聲驗證預覽](驗證預覽.mp4)：4.5 秒管線示範。

## 原始素材與完整下載

原始 MP4、三個 ZIP、28 張解壓圖片、參考索引、預覽及全部文件，保留在 [v1.0.0 完整素材包](https://github.com/louiskinghugo/zine-travel-edit/releases/tag/v1.0.0)。下載並解壓完整包後，`驗證時間表.json` 可直接使用相對路徑重新產生預覽。

GitHub 檔案列表保留 Skill、分析、腳本、參考索引及預覽；完整包另外保留 `素材/原始/` 和 `素材/圖片/`。原始檔以 A、B、C、D 短檔名存放，原始名稱與 SHA-256 記錄於 `素材/來源清單.json`。所有文件與設定已改用相對路徑。

## 證據範圍

三個 ZIP 是靜態圖文，不含影片或音軌。MP4 以全片抽幀分析，聲音僅確認音軌並量測音量，未完成可靠聽辨或逐字轉錄。推測與重製建議已和觀察分開標示。

素材由使用者提供，用於本次風格分析；未對原作素材另行授予開源授權。原始圖片、影片與作品文字的權利歸各自權利人。
