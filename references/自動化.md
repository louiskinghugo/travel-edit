# 自動化使用方式

需要 Python 3.10 以上與 Pillow。影片處理另需可執行的 FFmpeg（含 libx264、select、showinfo、volumedetect）；不自動下載、安裝或上傳。所有命令在 PowerShell 執行，請替換成本機實際路徑。

```powershell
$py = '你的 Python 完整路徑'
$ff = '你的 ffmpeg.exe 完整路徑'
$script = '這個 Skill/scripts/media.py 的完整路徑'
& $py -X utf8 $script unpack '素材資料夾' '新的解壓目錄'
& $py -X utf8 $script inspect '影片.mp4' '新的檢視目錄' --ffmpeg $ff --interval 6
& $py -X utf8 $script render 'plan.json' '預覽.mp4' --ffmpeg $ff
```

`unpack` 僅處理資料夾直層 ZIP 與 MP4，不遞迴解開 ZIP 中的 ZIP；輸出檔案清單、SHA-256 與依數字排序的圖片索引。拒絕路徑逃逸、符號連結與單檔案庫展開超過 2 GB。解壓目錄必須尚未存在，失敗時可能保留部分解壓資料，請換新目錄重試，不會自動刪除既有檔。

`inspect` 從 0 秒依指定間隔擷取實際時間點，產生有時間標籤的索引、格式資訊、畫面變化候選與音量量測。這不是音訊轉錄，也不是經人工核實的逐鏡分析；面板開關和全白畫面可能誤觸切點偵測。長片建議先用較大間隔。沒有音軌則略過音量量測。

`render` 讀取以下結構。圖片路徑相對於 JSON 所在目錄；也可用絕對路徑。每張以等比縮放居中放在背景上，依次硬切。輸出為 H.264／yuv420p／無聲 MP4，拒絕覆寫既有輸出。它不會自動生成旁白、配樂、動態縮放、字幕、去背或可編輯剪映專案。

```json
{
  "寬": 960,
  "高": 720,
  "每秒影格": 30,
  "背景": "#eee9df",
  "分鏡": [
    {"圖片": "封面.jpg", "秒數": 4},
    {"圖片": "跨頁.jpg", "秒數": 6}
  ]
}
```

內附 `驗證預覽.mp4` 僅用三張參考圖建立約 4.5 秒無聲硬切示範，用於驗證圖片方向、留邊、排序與輸出管線，不是模仿完整原作的最終影片。參考圖不是本 Skill 的可再散布素材庫，使用者更換素材後應重建預覽。
